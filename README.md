# Inven Go - 个人轻量化智能库存管理工具

## 项目简介

基于 **React Native + Expo** 构建，由 AI 辅助全程零代码（Vibe Coding）开发的安卓库存管理工具。

面向个人仓库、小店、工作室等轻量场景，用一部手机完成商品的扫码入库、出库、盘查与数据备份，数据全部保存在本机，不依赖任何服务端。

## 核心功能

- **双列瀑布流库存展示与低库存自动升序预警（红/黄/绿状态）**；
- **摄像头连续扫码三合一**（入库 +1、出库 -1、居中高亮查询）；
- **多条码同一商品绑定与即时模糊检索**；
- **多维日志流水**（支持操作类型与时间范围组合筛选）；
- **多重安全数据库备份**（剪贴板一键迁移、本地快照秒级还原、高危清空二次验证）；
