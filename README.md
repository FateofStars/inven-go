# Inven Go - 个人轻量化智能库存管理工具

## 项目简介

基于 **React Native + Expo** 构建，由 AI 辅助全程零代码（Vibe Coding）开发的安卓库存管理工具。

面向个人仓库、小店、工作室等轻量场景，用一部手机完成商品的扫码入库、出库、盘查、置顶排序、条码维护、多数据库管理与数据备份，数据全部保存在本机，不依赖任何服务端。

## 核心功能

- **双列库存网格与即时搜索**：低库存自动升序排前，0 件标红、1 件标黄，缺货与紧张商品一眼可见；支持按名称实时模糊检索；
- **多数据库管理**：在「数据库管理」里新建、重命名、切换、删除与重置多座数据库，每座库的商品、日志与本机快照完全隔离；升级后旧版数据会自动收纳为「默认数据库」，不会丢失；每座库的卡片右滑可导入 / 导出该库备份，左滑可改名或删除，弹窗顶部始终标注当前操作的数据库；
- **商品置顶与长按拖拽排序**：商品详情页右上角一键置顶，置顶商品固定展示在首页最前方，长按 0.5 秒即可拖拽调整置顶顺序（震动反馈、卡片抬起悬浮、虚线落位槽、拖出置顶区自动兜底到末行同侧槽位）；
- **摄像头扫码三合一**：入库自动 +1、出库自动 -1、库存查询弹出库存卡片；入库可设定本次入库数量，扫到新条码可直接创建商品；
- **智能扫码冷却**：命中有效商品后 3 秒内不再重复识别，避免同一件商品被连续计数；扫到未登记条码不锁死，可立刻连扫下一个；
- **商品详情与多条码管理**：库存支持 -1 / +1 快捷调整与步进器微调（左右点按改数量、中间直接输入，并自动避让虚拟键盘），可新增绑定条码、左滑修改或删除条码，并支持置顶与删除商品；
- **多维日志流水**：按数据库各自记录，支持关键词搜索，并按操作类型与时间范围组合筛选，覆盖入库、出库、新增、删除、条码更新与导入导出；
- **多重安全数据备份**：每座数据库都支持系统分享、剪贴板、本机快照三种导出与恢复通道，导出时可选择是否携带历史日志，导入支持「合并」与「覆盖」两种方式，且严格只作用于当前操作的那座库；新建数据库时也可先导入一份已有备份作为初始数据；
- **兼容与防护**：导出 JSON 兼容旧版本单库备份文件（导入时无缝转为当前库数据），高危操作要求二次验证。
